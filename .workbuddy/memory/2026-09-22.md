## 阻塞：用户 GitHub 2FA 验证码拿不到

浏览器登录卡在 TOTP 输入。本机钥匙串里没有任何 github.com 凭据（无 PAT、无 SSH key）。

给用户的恢复顺序：恢复码 → 换验证方式（短信/security key）→ 换手机丢失的话查 Authenticator
云同步（Authy/1Password/MS Authenticator）→ 其他仍登录的设备上改 2FA → 账号恢复表单。

**关键判断**：GitHub 卡住不影响「其他 dsh 用户能装」这个最终目标——GUI 的 Add plugin 只查
npm registry，仓库只是锦上添花（dsh.so 收录 + 源码可审计）。所以 npm 那条线优先推进。
